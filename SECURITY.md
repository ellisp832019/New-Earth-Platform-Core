# Security Policy

## Principles

- local-first by default;
- no secrets committed to source control;
- schemas and registries are non-secret metadata;
- credentials belong in environment-specific secret stores;
- dependency and contract validation must fail closed on malformed critical metadata;
- generated reports must not expose secrets.

## Reporting

Treat security findings as private until reviewed.

## Supported versions

The current foundation line is `0.1.x`.
